This it TomType, a simple typing game inspired by MonkeyType. 
This was made just to improve my javascript skills and for the Stardance Challenge.

https://github.com/user-attachments/assets/e9a4fe36-f6e6-41d0-bd78-8495e14d99e2

Try the game [here](https://n0kira.github.io/TomType/)!

## Features:
- **Multiple Word Categories:** Practice typing with custom word packs:
  - 🇬🇧 English
  - 🇮🇹 Italian
  - 💻 Tech / Programming Terms
  - 🐱 Cat-themed Vocabulary
  - 📜 Quotes
- **Game Modes:**
  - **Normal:** errors are highlighted in red and you can keep going.
  - **Hardcore:** 1 mistake and the test ends immediately.
- **Customizable Targets:**
  - **Time Modes:** 15s, 30s, or 45s timers.
  - **Word Count Modes:** 10, 25, or 50 words.

## Built with:
- **HTML5** / **CSS**
- **Vanilla JavaScript**
- **External Libraries:**
  - [`html-to-image`](https://github.com/bubkoo/html-to-image) – Used to share stats
  - [`FileSaver.js`](https://github.com/eligrey/FileSaver.js) – Saving files

## To run locally:

1. Clone the repo:
```bash
git clone https://github.com/n0kira/TomType
cd TomType
```

2. Open index.html
